## [1.0.0] - 2026-09-24

### Added
- Initial release of **Spec9ick-Ki8-Li934r** by **9icksA**.
- 7-Stage specification workflow: `specify`, `clarify`, `analyze`, `plan`, `checklist`, `tasks`, and `implement`.
- Linear GraphQL integration for reading issues, posting versioned comments, and creating sub-issues.
- Non-destructive versioning (`v1`, `v2`, ...) for repeated runs of identical stages.
- Automatic system clipboard copy ("Paste your way through the flow") with next command handoff.
- Just-in-Time git branch creation at the `implement` stage using Linear's canonical `branchName`.
- Automatic issue resolution from issue links, issue keys, or the current git branch name fallback.
- Next.js interactive web applet and playground with real Linear API integration + interactive sandbox simulation.
